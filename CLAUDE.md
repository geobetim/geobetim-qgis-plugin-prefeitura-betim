# Prefeitura de Betim — Plugin QGIS

Plugin QGIS ("Prefeitura de Betim") com um provider do Processing que reúne
algoritmos de edição da camada de trechos-logradouros
(`betimtaurus:TRECHOLOGRADOURO`): numeração automática por logradouro e
"Quebrar e remover trechos de passagem".

## Agent skills

### Issue tracker

Issues e specs vivem como markdown em `.scratch/<feature>/` (`spec.md` e
`issues/NN-slug.md`). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` na raiz. See `docs/agents/domain.md`.
